# Screenshots

Capture evidence from your own run and save sanitized PNGs here. Suggested files:

- `kind-node-ready.png`
- `monitoring-pods-ready.png`
- `grafana-restart-dashboard.png`
- `grafana-alert-firing.png`
- `grafana-alert-cleared.png`

Before committing, blur AWS account identifiers, public IP addresses, usernames, email addresses, browser tokens, and secret values. Avoid showing credentials in terminal history or screenshots. No runtime screenshots are included until the project owner adds their own captures.
